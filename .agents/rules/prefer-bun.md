# Regla de Proyecto: Preferir Bun

* Utilizar siempre **`bun`** como gestor de paquetes y runtime predeterminado para este proyecto (`bun install`, `bun add`, `bun run dev`, `bun run build`, `bun test`).
* Evitar el uso de `npm`, `yarn` o `pnpm`.
* Al ejecutar herramientas de CLI temporales, usar preferentemente `bunx` en lugar de `npx`.
